# Read Ticket (Azure DevOps Override)

Use Azure DevOps fields when extracting requirements:
- Work Item type (User Story, Bug, Task)
- Description and Acceptance Criteria section
- Area Path and Iteration Path
- Tags, Priority, and Severity
- Links (Related, Depends on, Parent/Child)

Acceptance Criteria format guidance:
- Prefer bullet lists under the Acceptance Criteria heading
- Treat checklists as explicit criteria

If required fields are missing or the Work Item is in a status that implies incomplete requirements, comment with questions and stop.
